============================================================
  AlanPOS Print Server — คู่มือติดตั้ง
============================================================

Print Server ทำให้เครื่องพิมพ์ใบเสร็จทำงานกับ AlanPOS โดยอัตโนมัติ
รันเป็น Windows Service — เริ่มอัตโนมัติทุกครั้งที่บูตเครื่อง


──────────────────────────────────────────────────────────────
  ขั้นตอนการติดตั้ง (ครั้งแรก)
──────────────────────────────────────────────────────────────

  1. ติดตั้ง Node.js (ถ้ายังไม่มี)
     - เปิดเบราว์เซอร์ไปที่: https://nodejs.org/en/download/
     - เลือก  Windows Installer (.msi)  รุ่น LTS
     - ติดตั้งตามปกติ แล้วรีสตาร์ทคอมพิวเตอร์

  2. ต่อเครื่องพิมพ์ USB เข้ากับคอมพิวเตอร์
     - ตรวจสอบว่า Windows เห็นเครื่องพิมพ์แล้ว
       (Settings → Bluetooth & devices → Printers & scanners)

  3. คลิกขวา  install.bat  แล้วเลือก "Run as administrator"
     - กด "Yes" ถ้า Windows ถามว่าอนุญาตให้เปลี่ยนแปลงเครื่อง

  4. รอประมาณ 1-2 นาที
     - ตัวติดตั้งจะตรวจจับเครื่องพิมพ์อัตโนมัติ
     - ติดตั้ง dependencies และ Windows Service

  5. เสร็จสิ้น!
     - หน้าต่างจะแสดง "[OK] ติดตั้งสำเร็จ!" และ Status: RUNNING
     - Print Server จะรันอัตโนมัติทุกครั้งที่บูตเครื่อง
     - ตรวจสอบสถานะได้ที่: http://localhost:12345/status


──────────────────────────────────────────────────────────────
  ตรวจสอบว่า Print Server ทำงาน
──────────────────────────────────────────────────────────────

  เปิดเบราว์เซอร์แล้วไปที่:
  http://localhost:12345/status

  ถ้าหน้าโหลดได้ = Print Server กำลังทำงาน ✓
  ถ้าหน้าไม่โหลด = Print Server ไม่ทำงาน (ดูส่วน Troubleshooting)


──────────────────────────────────────────────────────────────
  Troubleshooting (แก้ปัญหา)
──────────────────────────────────────────────────────────────

  ปัญหา: http://localhost:12345/status ไม่โหลด
  แก้:   เปิด Services.msc → หา "AlanPOS Print Server"
         → คลิกขวา → Start

  ปัญหา: พิมพ์ไม่ออก แต่ /status โหลดได้
  แก้:   ตรวจสอบชื่อเครื่องพิมพ์ใน POS Settings
         ชื่อต้องตรงกับที่ Windows เห็น
         (Settings → Bluetooth & devices → Printers & scanners)

  ปัญหา: install.bat เปิดแล้วปิดเลย
  แก้:   ต้องคลิกขวา → Run as administrator
         (ไม่ใช่ดับเบิลคลิก)

  ปัญหา: "Node.js not found"
  แก้:   ติดตั้ง Node.js แล้วรีสตาร์ทคอมพิวเตอร์ก่อน
         จากนั้นรัน install.bat ใหม่

  ไฟล์ Log อยู่ที่: C:\AlanPOS\logs\


──────────────────────────────────────────────────────────────
  ถอนการติดตั้ง
──────────────────────────────────────────────────────────────

  คลิกขวา  uninstall.bat  แล้วเลือก "Run as administrator"


──────────────────────────────────────────────────────────────
  ไฟล์ในโฟลเดอร์นี้
──────────────────────────────────────────────────────────────

  install.bat        — ตัวติดตั้ง (รันครั้งแรก)
  uninstall.bat      — ถอนการติดตั้ง
  server.js          — Print Server (Node.js)
  winsw.exe          — Windows Service Manager
  package.json       — Node.js dependencies
  INSTALL_README.txt — คู่มือนี้

  หลังติดตั้ง ไฟล์ทั้งหมดจะอยู่ที่ C:\AlanPOS\
