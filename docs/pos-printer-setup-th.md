# ติดตั้งเครื่อง POS + เครื่องพิมพ์ใบเสร็จ (Xprinter XP-T80A, USB)

ทำครั้งเดียวต่อเครื่อง ใช้เวลาประมาณ 10 นาที ผลลัพธ์: ไอคอน **Alan POS** บนหน้าจอ กดแล้วเปิด POS เป็นหน้าต่างแอป
และพิมพ์ใบเสร็จออกเครื่อง Xprinter ทันที ไม่มีหน้าต่างถามเครื่องพิมพ์ พิมพ์ภาษาลาว/ไทย/อังกฤษได้

ต้องมี: Windows 10/11, Microsoft Edge (มีมากับ Windows), อินเทอร์เน็ต, เครื่องพิมพ์ Xprinter ต่อ USB

## วิธีทำงาน (สั้นๆ)

- POS สร้างใบเสร็จเป็นหน้าเว็บ แล้วสั่งพิมพ์ผ่านไดร์เวอร์ Windows ตัวอักษรลาว/ไทยจึงออกครบ
  (วิธีส่งคำสั่ง ESC/POS ตรงเข้าเครื่องพิมพ์แบบเก่าพิมพ์ได้แค่ภาษาอังกฤษ)
- ไอคอน Alan POS เปิด Edge แบบ `--kiosk-printing` ในโปรไฟล์ของมันเอง จึงพิมพ์ทันทีโดยไม่ถามเครื่องพิมพ์
  และจำว่าต้องพิมพ์ไปที่ Xprinter เสมอ โดยไม่ต้องเปลี่ยนเครื่องพิมพ์หลักของ Windows
- ไม่ต้องเปิดโปรแกรม print server (เลขพอร์ต 12345 แบบเดิม) อีกแล้ว

## ขั้นที่ 1 — ติดตั้งไดร์เวอร์ Xprinter

1. ต่อสาย USB เครื่องพิมพ์เข้าคอม เปิดเครื่องพิมพ์ ใส่กระดาษ 80 มม.
2. ดาวน์โหลดไดร์เวอร์จากเว็บทางการ https://www.xprintertech.com/drivers-2 → เลือก **Xprinter receipt driver**
   (ที่ใช้ทดสอบ: `Xprinter.receipt.driver.2025.10.22.01.exe` ลงชื่อโดย Zhuhai Hena)
3. เปิดไฟล์ → กด **Yes** ที่หน้าต่าง "อนุญาตให้แอปนี้ทำการเปลี่ยนแปลง"
4. ในตัวติดตั้ง เลือกรุ่น **XP-80** และพอร์ต **USB** (เช่น `USB002`, ตัวเลขแต่ละเครื่องไม่เหมือนกัน) → ติดตั้ง
5. ตรวจ: Settings → Bluetooth & devices → Printers & scanners ต้องมี **Xprinter XP-80**
   กดเข้าไป → Print test page ต้องมีกระดาษออก

## ขั้นที่ 2 — เครื่องพิมพ์หลักของ Windows

Windows มีค่า "ให้ Windows จัดการเครื่องพิมพ์หลัก" ที่เปิดไว้ตั้งแต่แรก ค่านี้จะเปลี่ยนเครื่องพิมพ์หลักเป็นเครื่องที่ใช้ล่าสุดเอง
หลังพิมพ์ใบเสร็จครั้งแรก งานพิมพ์จาก Word/PDF จะไปออกเครื่องใบเสร็จ

- **คอมที่ใช้งานอื่นด้วย (มีเครื่องพิมพ์เอกสาร เช่น HP):**
  Settings → Bluetooth & devices → Printers & scanners → **ปิด** "Let Windows manage my default printer"
  (ให้ Windows จัดการเครื่องพิมพ์ค่าเริ่มต้นของฉัน) → กดเครื่องพิมพ์เอกสาร → **Set as default**
  POS ยังพิมพ์ออก Xprinter ตามปกติ เพราะไอคอน Alan POS จำเครื่องพิมพ์ไว้เอง
- **เครื่อง POS ในร้านที่ใช้ขายอย่างเดียว:** ตั้ง Xprinter เป็นเครื่องพิมพ์หลักได้เลย (กด Xprinter XP-80 → Set as default)
  ยังแนะนำให้ปิด "Let Windows manage…" เพื่อไม่ให้มันเปลี่ยนเอง

## ขั้นที่ 3 — สร้างไอคอน Alan POS

1. **ปิดหน้าต่าง Alan POS ทั้งหมดก่อน** (ถ้าเคยสร้างไว้)
2. ดาวน์โหลดสคริปต์ (คลิกขวา → Save link as… เก็บไว้ที่ Downloads; ใช้ได้หลังโค้ดชุดนี้ push ขึ้น `main` แล้ว):
   https://raw.githubusercontent.com/Parzy2212/alan-coffee-travel/main/docs/pos-setup/create-pos-shortcut.ps1
3. กด Start พิมพ์ `powershell` → เปิด **Windows PowerShell** (แบบปกติ ไม่ต้อง Run as administrator) แล้ววาง:
   ```
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\create-pos-shortcut.ps1"
   ```
4. ต้องเห็นข้อความ `Receipt printer: Xprinter XP-80` และ `Created: ...Alan POS.lnk` 2 บรรทัด
   (ไอคอนบน Desktop และใน Start menu)

สคริปต์**ไม่**เปลี่ยนเครื่องพิมพ์หลักของ Windows และไม่ต้องใช้สิทธิ์ admin

## ขั้นที่ 4 — เข้าใช้ครั้งแรก

1. ดับเบิลคลิก **Alan POS** → หน้าต่างแอปเปิดที่ `/pos`
2. ล็อกอินด้วยอีเมล/รหัสผ่าน owner (ทำครั้งเดียว หน้าต่างนี้จำไว้) → กลับมาที่ POS เอง → ใส่ PIN พนักงาน
3. ⚙️ POS Settings → ส่วนเครื่องพิมพ์: ต้องขึ้น **🖨 พิมพ์ผ่านไดร์เวอร์ Windows** และช่อง **ชื่อเครื่องพิมพ์ (Print Server แบบเก่า)
   ว่างไว้** (ถ้ามีชื่อค้างอยู่ ให้ลบแล้วกด **บันทึก** ก่อน ไม่งั้นระบบใช้วิธีเก่าที่พิมพ์ลาวไม่ได้)
   → กด 📄 ทดสอบพิมพ์ ต้องออกทันทีโดยไม่มีหน้าต่างถาม
4. พิมพ์อัตโนมัติ: ⚙️ POS Settings → บนสุดของส่วนเครื่องพิมพ์ **พิมพ์ใบเสร็จทันทีหลังรับเงิน** เปิดไว้เป็นค่าเริ่มต้น
   (ตั้งแยกแต่ละเครื่อง วันไหนไม่อยากพิมพ์ให้ปิดแล้วกดบันทึก) — บิลไหนต้องการใบเสร็จ กด **คิว & ออเดอร์** → 🖨 ที่บิลนั้น
   พิมพ์ซ้ำได้ ใช้ภาษาเดิมของบิล
5. ขายทดสอบ 1 บิลในโหมดทดสอบ เลือกภาษาใบเสร็จ ลาว / ไทย / อังกฤษ → ใบเสร็จต้องขึ้นตัวอักษรครบ มีแถบ TEST ORDER
   ชื่อร้านชิดด้านบน ไม่มีวันที่/URL ของเบราว์เซอร์ ไม่มีกระดาษเปล่าออกต่อท้าย

พนักงานใช้งานประจำวัน: กดไอคอน **Alan POS** อย่างเดียว อย่าเปิด POS จาก Chrome/Edge ปกติ
(ในเบราว์เซอร์ปกติจะมีหน้าต่างถามเครื่องพิมพ์ทุกครั้ง)

## แก้ปัญหา

| อาการ | ทำอย่างนี้ |
|---|---|
| สคริปต์ขึ้น `No Xprinter print queue found` | ยังไม่ได้ติดตั้งไดร์เวอร์ หรือเปลี่ยนชื่อเครื่องพิมพ์ → ทำขั้นที่ 1 ใหม่ หรือรันพร้อม `-Printer "ชื่อเครื่องพิมพ์"` |
| สคริปต์ขึ้น `Close the 'Alan POS' window first` | ปิดหน้าต่าง Alan POS แล้วรันใหม่ |
| กดพิมพ์แล้วมีหน้าต่างถามเครื่องพิมพ์ | เปิด POS จากเบราว์เซอร์ปกติ หรือมี Alan POS เปิดค้างก่อนกดไอคอน → ปิดทุกหน้าต่าง Alan POS แล้วกดไอคอนใหม่ |
| ใบเสร็จไปออกเครื่อง HP | เปลี่ยนชื่อ/ติดตั้งเครื่องพิมพ์ใหม่ → ปิด Alan POS แล้วรันสคริปต์ขั้นที่ 3 อีกครั้ง |
| ไม่มีอะไรออกเลย | ดูไฟเครื่องพิมพ์ / กระดาษ / สาย USB → Printers & scanners → Xprinter XP-80 → Open print queue ดูงานค้าง แล้ว Print test page |
| พิมพ์ภาษาลาวเป็น `?` | ช่องชื่อเครื่องพิมพ์ (Print Server แบบเก่า) ใน POS Settings ไม่ว่าง → ลบออก แล้วกดบันทึก |
| พิมพ์แล้วขึ้น "ส่งพิมพ์แล้ว" แต่ไม่มีกระดาษออก | เบราว์เซอร์รู้ไม่ได้ว่าเครื่องพิมพ์ออฟไลน์/กระดาษหมด งานจะค้างในคิวของ Windows → เช็คสาย USB/กระดาษ แล้ว Printers & scanners → Xprinter XP-80 → Open print queue (ถ้าเสียบกลับ งานที่ค้างจะพิมพ์ออกเอง) หรือยกเลิกงานแล้วกด 🖨 พิมพ์ซ้ำใน คิว & ออเดอร์ |
| กด 🖨 พิมพ์ซ้ำแล้วขึ้น "ไม่มีใบเสร็จของบิลนี้ในเครื่องนี้" | ใบเสร็จสำหรับพิมพ์ซ้ำเก็บไว้ในเครื่องที่ขาย เฉพาะบิลวันนี้ — บิลที่ขายจากเครื่องอื่น, ขายตอนออฟไลน์ หรือก่อนอัปเดตระบบ พิมพ์ซ้ำไม่ได้ |
| ใบเสร็จมีวันที่/URL หัวกระดาษ | ไม่ได้เปิดจากไอคอน Alan POS หรือหน้าเว็บเป็นเวอร์ชันเก่า → กด F5 |
| ลืมรหัสผ่าน | หน้าเข้าสู่ระบบ → "ลืมรหัสผ่าน?" |

## ถอนการติดตั้ง

1. ลบไอคอน **Alan POS** บน Desktop และใน Start menu
2. ลบโฟลเดอร์ `%LOCALAPPDATA%\AlanPOS` (วางในช่อง address ของ File Explorer) — ข้อมูลล็อกอินของหน้าต่าง POS อยู่ในนี้
3. (ถ้าไม่ใช้เครื่องพิมพ์แล้ว) Printers & scanners → Xprinter XP-80 → Remove และ Settings → Apps → ถอน Xprinter driver

## อนาคต: สาขาใหม่ / ไม่อยากลงไดร์เวอร์

ยังไม่ต้องซื้ออะไรตอนนี้ (ตัดสินใจ 2026-11-11: เครื่อง POS เครื่องเดียว ลงครั้งเดียวได้) ตัวเลือกเมื่อเปิดสาขา:

- **แท็บเล็ต Android + เครื่องพิมพ์ USB/Bluetooth:** Chrome บน Android ใช้ WebUSB ได้โดยไม่ต้องลงไดร์เวอร์
  แต่ต้องเขียนโค้ดส่งภาพใบเสร็จ (ลาว/ไทยต้องพิมพ์เป็นภาพ) และต้องตั้ง `public/manifest.json` ไม่ให้ล็อกแนวตั้ง
- **เครื่องพิมพ์คลาวด์ (Star CloudPRNT / Epson Server Direct Print):** เครื่องพิมพ์ดึงงานจากเซิร์ฟเวอร์เอง
  ใช้ได้กับทุกอุปกรณ์ ไม่ต้องลงอะไรที่เครื่องขาย แต่ต้องซื้อเครื่องพิมพ์รุ่นที่รองรับ และทำ endpoint ฝั่งเซิร์ฟเวอร์
- Windows + WebUSB ต้องเปลี่ยนไดร์เวอร์ USB เป็น WinUSB (Zadig) ซึ่งยุ่งกว่าลงไดร์เวอร์ Xprinter → ไม่แนะนำ
