### หน้าขายหลัก (`/pos`, `app/pos/POSClient.tsx`) — สถานะปัจจุบันจากโค้ด

**โครงสร้างจริง (ยืนยันจากโค้ด ไม่ใช่คาดเดา):**
- แถบบนสุด (header, สูง 56px, พื้น `#111`): โลโก้ "ALAN · Cafe OS" + นาฬิกา, ปุ่ม "พัก" (held orders, ไฮไลต์ทองเมื่อมีออเดอร์ค้าง), ปุ่ม "คิว & ออเดอร์", badge พนักงานที่ clock-in, ปุ่ม "ปิดกะ", toggle โหมดทดสอบ
- ใต้ header แบ่ง **grid 65% / 35%** (คอมเมนต์ในโค้ดเขียนว่า "60/40" แต่ตัวเลขจริงคือ 65/35):
  - **ซ้าย 65% (เมนู):** ช้นค้นหา (พื้น `#111`) → pill หมวดหมู่ระดับ 1 (ทองเมื่อ active) → pill หมวดหมู่ย่อยระดับ 2 (ถ้ามี) → grid การ์ดเมนู (`MenuCard`, auto-fill minmax 120px) พร้อม skeleton ระหว่างโหลด
  - **ขวา 35% (ตะกร้า+ชำระเงิน, พื้น `#111`):** หัวข้อ "ออเดอร์" + จำนวนชิ้น, ปุ่มเลือกลูกค้า (dashed border), รายการสินค้าในตะกร้าแบบการ์ด, ท้ายสุดเป็น "ยอดสุทธิ" (ทอง 22px) + ปุ่ม "พักออเดอร์" (outline) + ปุ่ม "ชำระเงิน" ตัวใหญ่ (สูง 56px, พื้นทอง, มี glow shadow, ตัวหนังสือใหญ่)
- ปุ่มลอย "?" (keyboard shortcuts) มุมล่างซ้าย
- Popup/Modal จำนวนมากซ้อนทับ (CustomPopup, ChargePopup, SettingsPopup, CustomerSelector, HoldModal, HeldOrdersModal, OrdersDrawer, ShiftClosePopup, ReceiptPreview, OrderSuccess, PinPad) — ยังไม่ได้เข้าไปดูรายละเอียดสีของแต่ละ popup ในบรีฟนี้

**สิ่งที่ Claude Design ควรรู้ก่อนเริ่ม:** ไฟล์นี้ยาว 3,777 บรรทัด สีที่ใช้อยู่ตอนนี้เป็น local constants (`GOLD`, `BLACK` ฯลฯ) ที่ประกาศแยกในไฟล์ ไม่ได้ดึงจาก `pos-theme-tokens.ts` — ถ้าจะรีดีไซน์ แนะนำให้ตัดสินใจพร้อมกันว่าจะ "swap ไปใช้ token ไฟล์ใหม่" ไปในตัวเลยหรือไม่ (ตามที่คอมเมนต์ในไฟล์ token ระบุไว้ว่าเป็น "separate follow-up refactor")

### หน้าจอคิว (`/queue`, `app/queue/QueueClient.tsx`) — สถานะปัจจุบันจากโค้ด

หน้าจอนี้คนละบริบทกับ POS — เป็นจอแสดงผลลูกค้า (TV/kiosk แนวนอน) ไม่มี interaction ให้กด

**โครงสร้างจริง:**
- แบ่ง 2 ส่วนแนวนอน: **แผงซ้าย 28%** (พื้น `#060606`, มีเส้นขอบทองบางๆ) กับ **พื้นที่ขวา** (คอลัมน์คิว)
- แผงซ้าย: วงกลมโลโก้ (ขอบทอง 3px, ตัวอักษรแรกของชื่อร้านตรงกลาง) → ชื่อร้าน (ตัวใหญ่ขาว) → เส้นคั่นทอง → วันที่ → **นาฬิกาทองตัวใหญ่มาก** (`clamp(36px, 5.5vw, 76px)`) → เส้นคั่น → label "QUEUE DISPLAY" จางๆ → ป้ายข่าววิ่ง (ticker) สกอลต่อเนื่อง 32 วินาที/รอบ ที่ขอบล่างสุดของแผง
- พื้นที่ขวา: คอลัมน์ "🔄 กำลังทำ" (สีทอง) กับคอลัมน์ "พร้อมแล้ว" (สีเขียว `#4cba7f`) — แต่ละออเดอร์เป็นการ์ดตัวเลขคิวขนาดใหญ่มาก (`clamp(44px, 5.5vw, 80px)`) การ์ดใหม่ที่เพิ่งพร้อมจะไฮไลต์ (border/background เข้มขึ้น + glow + เสียง beep) แล้วค่อยจางลงหลัง 1.2 วินาที
- แถบล่างสุด: สรุปจำนวน "กำลังทำ N คิว" / "พร้อมแล้ว N คิว" ตัวจางบางๆ

**สิ่งที่ Claude Design ควรรู้:** ค่าสีประกาศเองในไฟล์ (`GOLD`, `GREEN`, `BLACK` ที่ท้ายๆ ต่างจาก POS เล็กน้อย เช่น `BLACK = '#0a0a0a'` ที่นี่ vs POS ใช้ `#111`/`#0f0f0f` ผสมกัน) — ใช้ `clamp()` เยอะเพราะออกแบบมาให้รองรับจอทีวีหลายขนาด ไม่ใช่ responsive breakpoint แบบเว็บทั่วไป
